# Synthetic data registry: coursework

Every synthetic dataset the coursework workstream reads or creates. All have `is_synthetic = 1`, live
under a path containing `synthetic`, and are marked in code with `# SYNTHETIC:`. Coursework creates
**no DB tables**.

| File / table | Imitates | How generated | Real source that replaces it | Swap steps |
|---|---|---|---|---|
| live-sim `syn_scouts`, `syn_scout_reports`, `syn_points_ledger`, `syn_bounties`, `syn_scout_reputation_history`, `syn_scout_truth` in `data/live_sim.db` (owned and registered by live-sim; coursework only reads) | Scout accounts, reports, points, bounties, reputation history; truth for evaluation | `python -I -m simulator --seed 42 --out data/live_sim.db` (**not yet available**: no `simulator/` on `origin/nightlife/live-sim` as of b94468f) | backend tables `scouts`, `scout_reports`, `points_ledger`, `bounties`, `scout_reputation_history` (CONTRACTS v2 §E); no truth table exists in real life | point `LIVE_SIM_DB` / `churn/load.py` at the real DB (read with `INCLUDE_SYNTHETIC=0`), rerun `run_coursework.sh`, skip `evaluate_truth.py` |
| `coursework/churn/outputs/synthetic/standin_scouts.csv`, `standin_scout_reports.csv`, `standin_points_ledger.csv`, `standin_bounties.csv`, `standin_scout_reputation_history.csv`, `standin_scout_truth.csv` (**fallback, in use now**, not committed: rebuilt by the run script) | the six live-sim tables above, same columns, Thu–Sat Aug 27 → Nov 14 2026, 150 Scouts, IDs `syn-s-####`, `syn-r-######`, `syn-b-#####`, `syn-l-######` | `coursework/churn/make_standin_data.py --seed 0`: decaying Poisson engagement (λ₀ ~ Gamma(2.5, 1.5)/week, τ ~ LogNormal(ln 5, 0.6) weeks), Saturday ×1.5, bounty claim +30% for 14 days, quit when λ < 0.35/week or 3%/week hazard; launch cohort 30 Scouts then ~11/week; 35 real launch venues | live-sim's `data/live_sim.db`, then the real backend tables | 1) build `data/live_sim.db` with the contract command; 2) `load.py` picks it automatically (`--source db` to force); 3) rerun `bash coursework/run_coursework.sh`; 4) delete `standin_*.csv`; 5) update this row |
| `coursework/churn/outputs/synthetic/churn_dataset_2026-10-01.csv`, `churn_dataset_2026-10-22.csv` (not committed) | one modelling row per eligible Scout (features + label) | `build_dataset.py` from the tables above | the same table built from real reports | automatic once the inputs are swapped |
| `coursework/churn/outputs/synthetic/scout_churn_risk.csv` (committed, 86 rows) | churn risk per Scout at the Oct 22 cutoff (`scout_id, cutoff, churn_prob, is_synthetic`) | `train_eval.py` (selected model) | predictions on real Scouts | automatic |
| `coursework/churn/outputs/report.md`, `metrics.json`, `*.png`, `churn/churn.ipynb` outputs | results on synthetic Scouts (titles say "(synthetic data)") | `train_eval.py`, `explain.py`, `evaluate_truth.py`, `make_notebooks.py` | results on real Scouts | rerun |
| `coursework/tiny_transformer/outputs/synthetic/generated_names.csv` (committed, 20 rows), `outputs/sampling.json` | venue names | `sample.py` from TinyGPT trained on **real** SLA names | n/a: generated by nature | keep `is_synthetic=1`; never show as real venues |
| `coursework/tests/fixtures/synthetic/standin_*.csv` | 3 Scouts / 9 reports, hand-written for tests | by hand | n/a (test fixtures) | none |

Not synthetic: the transformer corpus (`data/manhattan_bars.db`, `venues.name`, public NY SLA licence
data) and `data/launch_venues.csv`.
